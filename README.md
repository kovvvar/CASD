# MyTreeMap на основе бинарного дерева поиска

## Суть программы

MyTreeMap — это собственная реализация отображения (Map), 
которое хранит пары «ключ-значение» в отсортированном виде.

Для хранения используется бинарное дерево поиска (BST).

## Принцип работы дерева

- Если ключ меньше текущего то идём в левое поддерево.
- Если ключ больше то идём в правое поддерево.
- Если ключ равен тогда обновляем значение.

Это позволяет быстро выполнять:
- поиск элемента
- добавление
- удаление
- получение минимального и максимального ключа
- поиск ближайших ключей (lowerKey, higherKey и т.д.)

## Основные возможности

- Put(key, value) — добавление пары
- Get(key) — получние значения по ключу
- Remove(key) — удаление элемента
- FirstKey() / LastKey() — минимальный и максимальный ключ
- HeadMap / SubMap / TailMap — получение части отображения
- LowerKey / HigherKey — поиск соседних ключей

## Компаратор

Компаратор определяет, как сравниваются ключи. 
По умолчанию используется естественный порядок сортировки.

## Сложность операций

В среднем:
- Поиск — O(log n)
- Добавление — O(log n)
- Удаление — O(log n)

В худшем случае (если дерево вырождается):
- O(n)
